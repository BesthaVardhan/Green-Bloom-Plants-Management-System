🌱 Green Bloom Plants Management System

📌 Project Overview

Green Bloom Plants Management System is a Python-based desktop application developed using Tkinter and MySQL. The application provides a user-friendly interface to manage plant records, suppliers, customers, billing, and business operations efficiently.

The main goal of this project is to simplify plant business management through a centralized desktop application.

🎯 Objectives

- To simplify plant record management.
- To maintain supplier and customer information.
- To manage billing operations efficiently.
- To organize plant business records.
- To provide a simple and user-friendly graphical interface.

✨ Features

- Plant Management: Manage plant-related records.
- Supplier Management: Maintain supplier information.
- Customer Management: Manage customer details.
- Billing Management: Handle billing operations.
- Reports: Generate and manage business reports.
- Database Connectivity: Store and retrieve information using MySQL.
- GUI Interface: Interactive desktop interface using Tkinter.

⚙️ Installation and Setup

Step 1: Clone the Repository

git clone https://github.com/BesthaVardhan/Green-Bloom-Plants-Management-System.git

Step 2: Navigate to the Project Directory

cd Green-Bloom-Plants-Management-System

Step 3: Install Required Dependencies

pip install -r requirements.txt

Step 4: Configure MySQL Database

1. Install and start MySQL.
2. Create the required database.
3. Import the "database.sql" file.
4. Update the database connection details in "db_connection.py".

Step 5: Run the Application

For the graphical interface, run:

python main_gui.py

If you want to use the command-line interface, run:

python main.py
